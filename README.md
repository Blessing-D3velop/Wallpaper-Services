Wallpaper Installation Service Website

A responsive and modern website built for a wallpaper installation service business.  
The website showcases services, projects, and provides an easy way for clients to get in touch.

Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Responsive Design (Flexbox & Media Queries)

Features

- Clean and modern landing page design
- Fully responsive for mobile, tablet, and desktop
- Services section showcasing wallpaper installation offerings
- Project/portfolio showcase section
- Contact section with email and WhatsApp integration
- Smooth scrolling navigation
- Mobile-friendly navigation menu

Purpose of the Project

This project was built for a real client to promote their wallpaper installation services and allow customers to easily view services and contact them for bookings.

Responsiveness

The website is fully responsive and optimized for:
- Mobile devices
- Tablets
- Desktop screens
